# نظام إدارة العهد والعاملين (Staff and Warehouse Management)

نظام سحابي متكامل لإدارة العمال، العهد، المخازن، والمصانع، مربوط بقاعدة بيانات سحابية Google Firebase.

## المميزات:
- تسجيل الدخول والتحقق الآمن عبر Google Firebase Authentication.
- قاعدة بيانات سحابية فورية (Realtime Database).
- إدارة بيانات العمال والموظفين وحالاتهم.
- إدارة العهد، صرفها، استرجاعها، ومتابعة حركتها.
- دعم اللغتين العربية والإنجليزية، والوضع المظلم والفاتح.
- تصدير التقارير واستيرادها وطباعتها.
